## 📖 About

**QR Code Generator** is a sleek, single-file web tool that generates **QR Codes** for 18 different content types — from plain text and URLs to WiFi networks, vCards, social media profiles, and cryptocurrency addresses. It runs entirely in your browser with no backend, no signup, and no tracking.

Whether you're a business owner creating a menu QR Code, a developer testing QR data, or someone who needs a quick QR Code for a link, this tool gets it done in one click.

## 🛠️ How to Use

1. Open the live demo
2. Choose a QR Code type from the tabs at the top
3. Fill in the fields
4. The QR Code is generated automatically in the right panel
5. Customize size, colors, and error correction level
6. Click **💾 Download PNG** or **📋 Copy** to save/use your QR Code

## 📚 QR Code Types Explained

| Type | Description | Use Case |
|------|-------------|----------|
| **Text** | Plain text | Instructions, notes, codes |
| **URL** | Website link | Marketing, packaging, posters |
| **Email** | `mailto:` link | Support pages, business cards |
| **SMS** | `SMSTO:` link | Customer feedback, registrations |
| **Phone** | `tel:` link | Storefronts, brochures |
| **WiFi** | `WIFI:` config | Cafes, hotels, offices |
| **vCard** | Contact card | Business cards, networking |
| **Location** | `geo:` coordinates | Event venues, real estate |
| **Event** | `VEVENT` calendar | Conferences, weddings |
| **Crypto** | Wallet address | Crypto payments |
| **Facebook/Instagram/LinkedIn** | Profile URLs | Marketing, business cards |
| **WhatsApp** | `wa.me` link | Customer contact |
| **YouTube** | Channel URLs | Content promotion |
| **Telegram** | `t.me` link | Community building |
| **Spotify** | Playlist/track URLs | Music promotion |
| **TikTok** | Profile URLs | Content promotion |
